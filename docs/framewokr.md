Agent 系统
│
├─ 一、内核：驱动一次完整的 Agent 运行
│  │
│  ├─ 1. 运行控制模块
│  │  ├─ 运行生命周期
│  │  │  ├─ 启动运行
│  │  │  ├─ 推进每一轮模型交互
│  │  │  └─ 完成、失败或停止
│  │  ├─ 循环控制
│  │  │  ├─ 判断模型是否请求工具
│  │  │  ├─ 决定继续下一轮还是结束
│  │  │  └─ 限制最大轮数
│  │  ├─ 停止与异常处理
│  │  │  ├─ 响应停止或取消
│  │  │  └─ 整理运行错误
│  │  └─ 运行输出
│  │     ├─ 运行事件
│  │     └─ 最终结果与状态
│  │
│  ├─ 2. 上下文模块
│  │  ├─ 输入准备
│  │  │  ├─ 接收历史消息
│  │  │  └─ 加入本次用户输入
│  │  ├─ 运行中消息管理
│  │  │  ├─ 记录模型响应
│  │  │  ├─ 记录工具调用与结果
│  │  │  └─ 加入运行时提醒或新指令
│  │  └─ 上下文整理
│  │     ├─ 向模型提供当前消息
│  │     └─ 按需要压缩或摘要历史
│  │
│  ├─ 3. 模型交互模块
│  │  ├─ 模型请求
│  │  │  ├─ 提供上下文
│  │  │  ├─ 提供系统提示词
│  │  │  ├─ 提供可用工具定义
│  │  │  └─ 提供模型调用参数
│  │  ├─ 模型响应处理
│  │  │  ├─ 接收流式文本
│  │  │  ├─ 识别工具调用
│  │  │  └─ 接收完整响应
│  │  └─ 调用信息
│  │     ├─ 模型用量统计
│  │     └─ 模型调用错误
│  │
│  ├─ 4. 工具调度模块
│  │  ├─ 工具请求处理
│  │  │  ├─ 识别工具名称与参数
│  │  │  ├─ 识别或生成调用 ID
│  │  │  └─ 查找对应工具
│  │  ├─ 调用约束
│  │  │  ├─ 检查当前允许运行的工具
│  │  │  ├─ 检查当前任务阶段的限制
│  │  │  └─ 对需要审批的调用请求审批
│  │  ├─ 工具执行
│  │  │  ├─ 调用具体工具
│  │  │  └─ 管理并发与运行停止
│  │  └─ 结果处理
│  │     ├─ 收集成功、失败或拒绝结果
│  │     └─ 将结果交还运行循环和上下文
│  │
│  └─ 5. 任务策略模块
│     ├─ 计划管理
│     │  ├─ 创建计划
│     │  ├─ 更新步骤状态
│     │  └─ 判断是否存在未完成步骤
│     ├─ 阶段管理
│     │  ├─ 规划阶段
│     │  ├─ 执行阶段
│     │  └─ 反思阶段
│     ├─ 反思与验证
│     │  ├─ 记录问题与处理思路
│     │  ├─ 判断是否需要重试或调整计划
│     │  └─ 判断修改后是否需要验证
│     └─ 策略判断
│        ├─ 各阶段的工具限制
│        ├─ 任务是否适合结束
│        └─ 向运行循环提供提醒或建议
│
├─ 二、外核：为内核运行提供具体能力与环境
│  │
│  ├─ 1. 模型接入
│  │  ├─ Gemini 客户端管理
│  │  ├─ 调用 Gemini SDK
│  │  ├─ 转换请求与响应
│  │  └─ 管理外部模型连接
│  │
│  ├─ 2. 具体工具
│  │  ├─ 文件与工作区
│  │  │  ├─ 列出文件
│  │  │  ├─ 读取文件
│  │  │  ├─ 写入文件
│  │  │  ├─ 编辑文件
│  │  │  └─ 加载 YAML
│  │  ├─ 命令与质量检查
│  │  │  ├─ 执行命令
│  │  │  └─ 执行固定质量检查
│  │  ├─ 网络信息
│  │  │  ├─ 搜索网页
│  │  │  └─ 获取网页内容
│  │  └─ 内部能力的工具入口
│  │     ├─ 更新计划
│  │     ├─ 提交反思
│  │     └─ 调用子 Agent
│  │
│  ├─ 3. 多 Agent 协作
│  │  ├─ 定义子 Agent 角色与可用工具
│  │  ├─ 创建和管理子 Agent 运行
│  │  ├─ 传递任务与上下文
│  │  ├─ 转发子 Agent 事件和审批请求
│  │  └─ 收集结果与清理运行资源
│  │
│  ├─ 4. 安全与权限
│  │  ├─ 工具访问策略
│  │  │  ├─ 按运行环境配置允许的工具
│  │  │  └─ 配置需要审批的操作
│  │  ├─ 审批实现
│  │  │  ├─ 向用户展示审批请求
│  │  │  └─ 接收批准、拒绝或超时结果
│  │  ├─ 工作区保护
│  │  │  ├─ 限制工具访问范围
│  │  │  └─ 检查敏感路径、链接等
│  │  └─ 输出安全审核
│  │     ├─ 审核模型输出
│  │     └─ 审核失败时协调停止运行
│  │
│  ├─ 5. 交互入口
│  │  ├─ CLI
│  │  │  ├─ 接收用户输入
│  │  │  ├─ 展示运行事件与结果
│  │  │  └─ 接收工具审批决定
│  │  └─ HTTP API
│  │     ├─ 接收请求与校验参数
│  │     ├─ 返回会话、运行和工具调用信息
│  │     ├─ 流式返回运行事件
│  │     └─ 接收工具审批决定
│  │
│  ├─ 6. 服务与持久化
│  │  ├─ 应用服务
│  │  │  ├─ 创建和查询会话
│  │  │  ├─ 准备与管理一次运行
│  │  │  └─ 协调 API、内核和数据库
│  │  ├─ 数据持久化
│  │  │  ├─ 保存会话与消息
│  │  │  ├─ 保存运行状态
│  │  │  ├─ 保存工具调用与审批记录
│  │  │  └─ 管理数据库连接与事务
│  │  └─ 数据转换
│  │     └─ 转换运行内容与存储格式
│  │
│  └─ 7. 配置与组装
│     ├─ 模型与运行参数
│     ├─ 系统提示词与安全提示词
│     ├─ API、数据库和工作区配置
│     ├─ 工具注册与运行环境工具表
│     └─ 为 CLI / HTTP 组装运行所需组件
│
└─ 三、项目支持：帮助开发、验证和部署
   ├─ 测试
   │  ├─ 单元测试
   │  ├─ 集成测试
   │  └─ 外部环境测试
   ├─ 数据库迁移
   ├─ 依赖与开发配置
   ├─ 容器与部署配置
   └─ 项目文档
