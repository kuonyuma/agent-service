# CLI 安全与权限边界

本文描述当前实现，不把策略提示或人工批准等同于系统沙箱。
HTTP API、SSE、数据库和持久化审批均已删除，项目只有本地 CLI 入口。

## 装配与依赖方向

`bootstrap.create_runner()` 将模型、工具注册表、工作区和子代理绑定工厂注入内核；
`bootstrap.create_app()` 在 Runner 外包装 `RunCoordinator`，再交给 CLI。
内核只负责通用调度规则与停止检查，不读取全局配置，也不依赖具体安全适配器。

直接使用 `AgentRunner` 不会自动启用输出审核；需要由调用者显式包装 Coordinator。
CLI 的输出审核、文件路径策略、审批分别解决不同问题，不能互相替代。

## 工具授权链

1. 每次运行的可用集合为 **声明 ∩ 注册表 ∩ 显式 allow-list**；未声明工具即使存在于注册表也不能执行。
2. 规划与反思阶段只声明、执行只读工具及相应策略工具。阶段按模型请求开始时的状态判断，同一批次创建计划不能顺带解锁写入。
3. `read_only=False` 的工具必须通过审批；缺少审批回调或拒绝都会生成错误工具响应，不执行工具。
4. 审批对象包含调用 ID、工具名、深复制参数及规范 JSON 的 SHA-256 指纹。审批后重新比对参数，回调篡改参数会拒绝执行。
5. 执行器再次校验 allow-list 和批准 ID。工具请求与响应使用相同 ID；缺失或重复 ID 由调度器补齐。
6. 子代理使用父级权限的交集，不能提权，不能继续创建孙代理。子代理的写操作仍经过父级审批和停止门闩。

审批仅对当前调用有效，没有数据库审批记录或跨运行复用的授权票据。
工具事件向消费者提供参数副本，修改事件参数不能改写待执行调用。

## 文件工具与命令

默认 CLI 工作区是启动时的当前目录，也可在 `create_runner(workspace=...)` 中指定。
具体文件工具使用 `WorkspacePathPolicy`：

- 仅接受工作区内的相对路径，拒绝绝对路径和路径逃逸。
- 拒绝敏感文件、符号链接及 Windows reparse point。
- 文件写入/编辑需要审批；读取与枚举也会经过同一条路径策略。

自定义注册表可替换这些工具，调用者必须自行保持路径边界。路径检查不是独立进程沙箱，
也不能消除恶意本地进程在检查与使用之间替换路径的所有竞争风险。

`run_command` 是经人工批准的本机任意 shell 命令，**不受文件路径策略约束**。
它还没有进程隔离、完整的命令超时和进程树终止；取消协程不保证终止已启动的命令。
非零退出码会返回错误，不能作为验证成功。
`run_quality_check` 只支持固定的 Ruff / Pyright 动作及受限环境，但仍会执行本机进程。
不要把项目当作能安全运行不可信代码的托管服务。

## 输出审核

`adapters/security/coordinator.py` 并发协调模型输出、审核、审批和终态。
审核器按字符数/时间阈值检查文本，模型审核结果由严格的 Pydantic 结构验证。
拒绝、审核异常、超时或积压超限会停止本次运行并发送 `safety.blocked` 与失败终态；
普通终态要等待剩余文本审核完成。

这不是“审核通过再显示”的网关：文本可能已短暂显示，CLI 收到拦截后会替换当前输出。
审核不提供执行前的代码安全检查，也无法回滚已经发生的工具副作用。
恢复历史来自完整检查点，不保存未成对的工具请求/响应。

## 规划、验证与完成

`TaskPolicy` 负责计划与反思策略，不是权限系统。
成功修改 `write_file` / `edit_file` 后记录待验证路径。
后续批次读取对应路径可核销该路径；成功的命令/质量检查可核销当前待验证集合。
同批次工具并发，读回不能证明发生在写入之后，因此同批次修改仍保持待验证。
子代理的验证不核销父级或其他子代理的修改，父级需要独立回读或自检。

这些记录不等同于测试覆盖率或正确性证明。`reflect(strategy="complete")` 仍可声明完成自检，
未完成计划/未验证修改的提醒也不是无限强制闸门；每次运行硬上限为 10 轮。
应以实际工具输出、退出码、测试结果和人工 review 为交付依据。

## 回归验证

`tests/integration/test_kernel_contracts.py` 覆盖声明和执行一致性、参数防篡改、
调用 ID 配对、异常/取消清理和轮数上限。
`tests/unit/test_workspace_path_policy.py` 等路径测试、审核测试以及子代理集成测试
分别验证各自边界。默认测试不访问真实模型、网络或运行真实 shell。
