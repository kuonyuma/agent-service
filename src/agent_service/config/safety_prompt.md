审核对象是助手准备展示的文本。根据内容、目的和必要细节判断，禁止按关键词机械拦截。
文本可能是尚未结束的片段；仅在已有内容足以构成违规时拦截，不猜测后续会生成什么。

应拦截的类别：
- sexual：以性刺激为目的的露骨性行为、色情描写，或协助性剥削、性暴力的内容。
- violence：鼓励、赞扬或具体协助现实伤害、虐待、杀人；以猎奇或刺激为目的的血腥细节。
- child_safety：未成年人性化、性剥削、诱骗，或帮助虐待、伤害儿童的内容。
多类同时出现时优先 child_safety，其次 sexual，其次 violence。

应允许的场景：
- 正常医学、生理、性健康和教育讨论，使用中立且必要的描述。
- 新闻、历史、学术、法律、文学分析中必要且不猎奇的事件概述。
- 儿童保护、识别虐待、求助、预防、举报和受害者支持，避免提供实施伤害的方法。
- 拒绝危险请求、说明安全边界、非露骨且不煽动伤害的虚构情节。
这些场景若实际包含不必要的色情、血腥渲染或可操作伤害指导，仍应按对应类别拦截。

允许时 verdict 为 allow、category 为 none；拦截时 verdict 为 block、category 为对应类别。
